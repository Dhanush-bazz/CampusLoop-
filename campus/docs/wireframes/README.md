# CampusLoop Wireframes

## Purpose

This directory contains a read-only export of the CampusLoop wireframe from
the connected Miro workspace. It documents the planned public, student,
organiser, and admin experiences, along with system states and user flows.
The export preserves the complete board layout and content; it is a
wireframe, not an implemented product UI.

## Miro reference

- Board title: [Weekly Update Writer](https://miro.com/app/board/uXjVETIm4Bk=/)
- Project identified from board content: CampusLoop
- Export scope: 388 Miro-managed items, including 29 frames and two flow
  diagrams.
- Separate interactive prototype screens: none reported by Miro.

## Included files

- [`campusloop-wireframe.svg`](./campusloop-wireframe.svg) — complete
  read-only SVG export of the board.

Miro MCP provides the full-board SVG read/export used here, but does not expose
a native PDF export. If a PDF is required, use the board's Export menu in Miro
to save the board as a PDF, then add that exported file to this directory.

## Major sections

1. **Public Experience** — Landing page, student sign-up, student login, and
   password recovery.
2. **Student Experience** — Student dashboard and event discovery, event
   exploration, event details, bookmarks, registrations, reminders, profile,
   plus mobile dashboard and event-detail screens.
3. **Organiser Experience** — Organiser login and dashboard, event creation
   and editing, event details/status, plus a mobile organiser dashboard.
4. **Admin Experience** — Admin login and dashboard, pending-event review,
   approval details, and approved/rejected event views.
5. **System States** — Empty states, error and validation states, success
   messages, and confirmation dialogs.
6. **User Flows** — Student flows (screens 1–5 and 9) and organiser/admin
   flows (screens 6–8), represented by two diagrams.

The SVG also retains board tables such as upcoming reminders, recent events,
recent submissions, and pending, approved, and rejected events.
